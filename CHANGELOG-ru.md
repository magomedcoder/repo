## v0.1.0 - 1 ноября 2026

- Аккаунты: регистрация, вход, выход, сессии, смена пароля, переключатель регистрации, блокировка после неудачных попыток входа
- Роли: user и admin; список, создание, изменение и удаление пользователей для админа в API и UI
- Профиль: публичная страница, смена email, загрузка и удаление аватара
- Access-токены: создание, список и отзыв в API и UI для Git HTTP
- Папки: создание, список, переименование, удаление; вложенная структура и пути репозиториев без префикса владельца
- Репозитории: создание, обновление, rename/move, удаление, описание, public и private, default branch, защита default branch, переключатели issues и pull requests
- Доступ: гостевое чтение публичных репозиториев; запись только после входа; настройки только у владельца
- Git по HTTP: clone, fetch, push; защита от force-push в защищённую default branch
- Просмотр: ветки, теги, дерево, blob, raw-скачивание, коммиты, diff коммита, blame, readme, summary, статистика
- Issues: открытие, закрытие, редактирование, удаление, комментарии, метки
- Pull requests: открытие, закрытие, редактирование, удаление, комментарии, diff, коммиты, merge
- Поиск репозиториев по имени; публичная главная
- Лента активности: push, issues, pull requests, создание репозитория
- YAML-конфиг: сервер, хранилище, имя сайта, cookies, сессии, регистрация, proxies и лимиты receive
- UI на английском и русском
- Rate limiting, CSRF, security headers; bootstrap схемы SQLite и версионированные миграции
- CLI для запуска сервера и создания пользователей
